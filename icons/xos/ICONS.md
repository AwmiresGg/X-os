# X-OS Icon System

Original artwork only. No third-party icon packs, no emoji, no vendor logos/trademarks.

## Glyph grid (all symbolic icons)

* `viewBox="0 0 24 24"`, artwork inside the 2–22 live area (2 px optical padding).
* Stroke only: `fill="none" stroke="currentColor" stroke-width="1.75" stroke-linecap="round" stroke-linejoin="round"`.
  Small solid details (dots, badges) may use `fill="currentColor"` with `stroke="none"`.
* Rectangles: `rx="2"` (large containers `rx="3"`); circles for round shapes; no hairlines < 1.5 px.
* No colours in the file: colour comes from the theme (`currentColor`) — default `text`, hover/active
  `accent`, disabled `textFaint`, warning/danger semantic colours only for state badges.
* Silhouettes: geometric, front-facing, centred on the optical centre; consistent visual weight
  (a filled-looking glyph must not appear heavier than its neighbours).
* Lighting/depth: none in glyphs (flat line art). Depth belongs to containers (app tiles, active circle).

## States

| State | How it is rendered |
|---|---|
| default | glyph in `text` |
| hover | glyph in `accent` (reference video: hovered icon turns teal) |
| active | glyph in `onAccent` inside the `accentDeep` circle (dock / menu bar cradle) |
| selected | glyph in `accent` + `surface2` row/pill background |
| disabled | glyph in `textFaint` |
| notification | glyph + 6 px dot at top-right (`accent`), optional count badge |
| warning / error | glyph + small triangle/circle badge in `warning` / `danger` |

State variants are *not* separate files; the badge glyphs (`badge-dot`, `badge-warning`, `badge-error`)
are overlaid by the shell.

## App tiles

`apps/*.svg` are generated by `scripts/build-icons.py` from glyphs: 64×64 squircle in
`surface2`, 1 px `borderStrong` rim, faint top highlight, glyph scaled to 32 px in `text`.
One shape, one material, monochrome — consistency like a single family, not a sticker sheet.

## Files

* `symbolic/<category>/<name>.svg` — glyphs (categories: `apps`, `status`, `places`, `devices`,
  `mimetypes`, `actions`, `window`, `shell`).
* `index.json` — generated metadata: name, category, keywords, file, used-by.
* `preview/contact-sheet.png` — generated preview of every glyph (dark + light).
